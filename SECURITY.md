# Security Policy

## Supported Versions

This tool is specifically designed and tested for the **360 11X W370** smartwatch (Unisoc SC8541E, Android 8.1, 32-bit ARM). It is provided as a Local Privilege Escalation (LPE) Proof of Concept (PoC). 

## Intended Use

This repository is intended for security research and educational purposes only. The GhostRoot persistence mechanism requires a pre-existing `uid=2000(shell)` environment. It is NOT a remote exploit. You are solely responsible for ensuring you have explicit permission to test this on any device. 

## Reporting a Vulnerability

If you find any errors, unintended behaviors, or have concerns regarding the dual-use nature of this research, please contact the author directly:

*   Email: huangxuanran.china@gmail.com
*   Alternatively, you can open an Issue in this repository.

Please do not disclose potential security risks to the public until we have had a chance to address them.
